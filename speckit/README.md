# Speckit del proyecto

Proyecto: tienda electrónica en WordPress para la marca Weirdlings.

Este directorio reúne la especificación base para desarrollar el sitio sin mezclarla con el código de WordPress.

## Contenido

- [spec.md](spec.md): visión general, alcance y supuestos.
- [requisitos-funcionales.md](requisitos-funcionales.md): lo que debe hacer el sitio.
- [requisitos-no-funcionales.md](requisitos-no-funcionales.md): rendimiento, seguridad y mantenimiento.
- [arquitectura.md](arquitectura.md): decisión técnica y estructura recomendada.
- [criterios-aceptacion.md](criterios-aceptacion.md): condiciones para dar por terminado cada bloque.
- [preguntas-abiertas.md](preguntas-abiertas.md): puntos pendientes de definir con el negocio.

## Supuestos iniciales

- El proyecto usa WordPress ya instalado en este workspace.
- La base de e-commerce será WooCommerce.
- El idioma principal del sitio será español.
- El foco del sitio es vender amigurumis y llaveros crochet con estética horror cute.
- La marca es Weirdlings, con personalidad extraña, tierna y artesanal.
