# Arquitectura recomendada

## Base técnica

- WordPress como CMS principal.
- WooCommerce para e-commerce.
- Tema propio `weirdlings-modern` como capa visual principal.
- `weirdlings-child` solo si hace falta una capa segura para ajustes menores o pruebas.
- Plugins mínimos necesarios para pagos, SEO, caché y formularios.
- El tema debe controlar la experiencia completa para que la tienda siga la misma estética en todas sus plantillas.

## Estructura de contenido

- Inicio.
- Tienda o catálogo.
- Categorías de producto.
- Producto individual.
- Sobre nosotros.
- Contacto.
- Envíos y devoluciones.
- Preguntas frecuentes.
- Colecciones o lanzamientos especiales si la marca trabaja por series.
- Blog con tono de universo de marca, no genérico.

## Modelo de producto

Cada producto debería poder describir, como mínimo:

- Nombre.
- Precio.
- Imágenes.
- Descripción corta y larga.
- Categoría.
- Etiquetas.
- Stock.
- Variantes si existen.
- Tiempo de elaboración o envío si aplica.
- Tipo de pieza: única, personalizada, por encargo o edición especial.
- Nombre de colección o serie si aplica.

## Recomendación visual

- Estilo horror cute artesanal, con equilibrio entre misterio y ternura.
- Tipografía legible con personalidad alternativa.
- Uso de negro carbón, morado profundo, verde neón apagado, rosa pastel desaturado y blanco hueso.
- Mucho protagonismo visual para fotografía real del producto y detalles de textura.
- Las secciones deben tener aire de póster/editorial, no de plantilla corporativa genérica.

## Sistema de placeholders

- El tema debe incluir imágenes temporales creadas en SVG o CSS para cuando no existan fotos finales.
- Los placeholders deben mostrar texto como `Placeholder` o `Imagen temporal` de forma elegante.
- Los placeholders deben servir para hero, tarjetas, avatar/logo y banners laterales.
